# Domain docs

This is a single-context repository.

Before changing domain behavior, read `CONTEXT.md` when it exists and any relevant decisions under `docs/adr/`. If those files do not exist, proceed without treating their absence as a blocker.

Use domain terms as defined in `CONTEXT.md` in issue titles, tests, interfaces, and documentation. Surface any conflict with an existing architectural decision instead of silently overriding it.
